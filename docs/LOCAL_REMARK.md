# 电脑专用备注（4.1.15.56）

目标：好友原昵称 CCCCC 不变，手机保留备注 A，电脑显示自定义 B。
用户已反馈选定好友的电脑显示、手机备注不变及重启持久化成功。

## 操作

微信登录时读取联系人，选择已有备注的普通好友，输入电脑显示文字，点击“应用电脑备注”。
按提示完全退出微信（包括托盘）后确认。工具自动检查副本、备份、写回和校验，然后可重新启动微信。
无需手动做兼容性检查或结束诊断。配置持久保存，失效时可复用保存文字重新应用。
“恢复电脑原备注缓存”写回首次保存的 A；维护菜单可清除备注配置或恢复未完成写入，两者含义不同。

## 实现

- 仅 `UPDATE contact SET remark=? WHERE username=?`，不修改 nick_name、wxid、标志、拼音、额外缓冲区或同步队列。
- 不点击微信官方备注界面，不调用备注提交 API，不安装服务、Hook 或常驻进程。
- 对 main/WAL/SHM 使用与头像后端相同的独占锁、加密校验、完整备份、事务副本、逐文件写回、失败回滚。
- 比较目标完整行，除 remark 外必须保持原值；比较所有非目标联系人及 contact.db 中其他数据表的数据摘要。
- 未知目标表触发器、非普通好友、无原始备注、缺失或重复记录、格式/版本不匹配均拒绝。
- 版本仅开放 4.1.15.56，所有写入均要求本次进程内、指定账号/目标/文字/策略/来源三文件绑定的单次副本证明。
- 头像库与联系人库的路径校验、备份目录、配置、恢复入口分开；禁止删除联系人记录。
- 正常应用不启动采样；内部诊断代码保留供自动化验证，不在正式界面显示。

## 验证边界

用户反馈仅覆盖其选定好友和环境，未逐一验证所有显示位置、拼音搜索、其他设备或未来联网同步行为。
工具只定向修改本机联系人缓存、不调用官方备注提交接口；保留同步字段不能证明已理解同步协议。
自动检查只能验证当前缓存，不能自动识别微信画面或手机状态，内部报告的客户端/远端验证布尔值仍保持 false。
若手机备注发生变化，应停止使用；恢复电脑缓存不是服务器资料恢复功能。
