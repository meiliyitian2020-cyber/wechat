# 微信本地头像替换工具（实验版）

版本权限：

| 微信版本 | 当前开放能力 |
|---|---|
| 4.1.13.65 | 实验性离线头像库写入、备份、回滚、失效检测 |
| 4.1.15.56 / 4.1.15.65 | 实验性读取；强制副本检查通过并明确选择后，仅本次试验写入 |
| 其他版本 | 拒绝读取及写入 |

升级后必须重新读取账号，禁止沿用旧版本上下文。副本检查通过不会自动写入；还需要明确选择仅本次试验操作。检查凭据只在内存中保留 5 分钟、单次使用，并绑定原文件、好友、图片、操作及微信版本。
**原版微信实际显示尚待实机验证，不保证会话、聊天和资料页都采用该头像库。昵称本地替换尚未实现，界面禁用。**
不调用官方备注接口，不修改 contact.db 或聊天数据库，不安装服务、驱动、计划任务、启动项或 Hook。

## 4.1.15.56 / 4.1.15.65 兼容性检查

1. 保持新版微信登录，打开本次 EXE 并读取联系人。
2. 选择一个测试好友及自定义头像，点击“新版兼容性检查（不写原库）”。
3. 保持工具打开，完全退出微信和托盘，再在工具弹窗确认。
4. 检查只会改临时加密副本，验证 SQLCipher 完整性、目标头像读回、表结构和其他好友记录。
5. 通过后点击“复制检查结果”，提供报告用于后续适配。报告只含版本、表列定义、结构哈希及检查状态；
   不含账号、好友 ID、昵称、头像、数据路径或密钥。副本及内存密钥不会被上传。
6. 需要测试实际头像时，选择“仅本次试验应用”，再次确认写入。工具会备份并验证后写回，
   重启微信检查会话、聊天窗口和资料页。此步骤属于未完成客户端验收的实验操作。
7. 原文件在检查后变化、图片更换、版本变化、超时或凭据已用都会拒绝写回，需要重新检查。
   “恢复当前真实头像”在新版也先执行删除目标记录的副本检查，再允许仅本次试验恢复。
   “一键重新应用”在确认后为每个失效好友强制重做副本检查，再试验应用，不会跳过检查。

## 4.1.13.65 实验性操作流程

1. 登录微信 Windows 4.1.13.65，打开工具，读取联系人。密钥仅保存在本次工具进程内存中。
2. 选中一个测试好友，选择 JPG/PNG/WEBP 头像（居中裁切为 128×128 PNG）。
3. 点击“应用至微信”，保持工具打开，**完全退出微信及托盘**，再确认继续。不要在写入期间启动微信。
4. 工具取得头像库独占句柄，建立加密备份，再事务性生成加密暂存副本、校验并写回。
5. 提示“数据库写入完成”后，重新打开微信，检查会话列表、聊天窗口、资料页及消息收发。
   该提示只证明头像库写入校验通过，不能当作客户端显示已通过。
6. 下次打开工具并读取账号后，会重新读取当前头像库及稳定复制的 WAL，比较所有已保存配置。
   发现已应用的头像不一致时，弹出“检测到本地头像替换失效”；可复用原图片一键重新应用。

微信退出后允许残留 WAL/SHM。工具独占这三个文件，在私有副本中验证 WAL 帧校验和及加密页 HMAC，
通过 SQLCipher 合并已提交日志，保留其他好友在 WAL 中的最新记录。原始三文件先完整备份，再写回合并后的主库，
清空现有 WAL/SHM 供微信重建，不删除它们。无法独占、格式未知或校验失败时停止。**不要手动删除这些文件**。
只支持通过逐页 HMAC 验证的标准 SQLCipher4 32 字节 raw key、4096 字节页、80 字节保留区；其他格式拒绝。
写回时只写改变的加密页，失败尝试精确恢复整个头像库的操作前字节，不触及聊天库。

## 清除与恢复

- “清除选中配置”：仅删除工具保存的图片和配置，不修改微信头像。
- “恢复当前真实头像”：清除该好友在头像库中的记录，让微信启动后尝试重新获取当前头像；不写回旧头像。
  微信其他文件缓存及实际重新下载行为尚未验证，不能保证客户端立即刷新。
- “故障恢复”：检查未完成的操作记录。已知写入前/后文件可回滚；若出现部分写入或其他程序后续修改，
  无法自动区分时会停止，保留备份。此时保持微信关闭，不要自行覆盖数据库。

配置和加密备份位于 `%LOCALAPPDATA%\WeChatLocalProfileEditor`。
备份中含联系人头像等个人数据，勿上传。解密暂存目录正常操作后清理；强制终止/断电可能留下临时文件。
本工具不联网发送微信资料，不记录密钥或消息。Python 无法保证进程内存密钥完全擦除。

## Windows EXE

仓库 Actions 的 `Windows experimental avatar editor build` 在 main 更新时自动构建，也支持手动运行。
先运行人工数据测试，再用 PyInstaller 输出单文件 `WeChatLocalProfileEditor.exe`。
构建通过与真实客户端验收是两件事，查看对应 Actions 结果，不要把尚未完成的构建当成成功。

## 从源码运行（Windows x64 / Python 3.12）

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-research.txt
.\.venv\Scripts\python.exe -m pytest -v
if ($LASTEXITCODE -ne 0) { throw '测试失败，请停止并提供错误日志' }
.\.venv\Scripts\python.exe main.py
```

本机测试只使用人工数据。无需 Git，可下载 GitHub 源码 ZIP。
Linux 开发使用同样 requirements-research.txt 和 pytest；无显示器设置 QT_QPA_PLATFORM=offscreen。
