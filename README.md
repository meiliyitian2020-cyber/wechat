# 微信本地头像与电脑备注工具（实验版）

Windows x64 单文件 `WeChatLocalProfileEditor.exe`，无需安装 Python，无后台服务、驱动、计划任务或常驻 Hook。

## 当前状态

- **头像**：只替换 `image_buffer`，保留 `md5` 和时间等原字段。用户在微信 4.1.15.56 上反馈该测试好友显示生效，且再次重启后保留；不能扩展为所有显示位置和所有好友均已验收。
- **本机备注覆盖试验**：目标是原昵称 CCCCC 不变、手机备注仍是 A、电脑独立显示 B。代码已实现本机 `contact.remark` 缓存试写及定向校验；电脑实际显示、手机/服务器仍为 A 尚未验收。
- 工具不调用微信官方备注提交界面或 API，但**离线改缓存仍不能保证微信登录后不会同步或覆盖**。本机备注功能必须先用测试联系人验收，不能标记为已验证的纯本地替换。

| 微信版本 | 头像 | 本机备注 |
|---|---|---|
| 4.1.13.65 | 实验性离线写回 | 禁止 |
| 4.1.15.56 | 副本检查后的单次试写 | 副本检查后的单次试写，远端不同步未验证 |
| 4.1.15.65 | 副本检查后的单次试写 | 禁止 |
| 其他版本 | 禁止读取、写入 | 禁止 |

更新微信后必须重新适配。数据库一致不能证明客户端实际显示一致。

## 双击 EXE 使用

从本仓库 Actions 最新成功构建下载 ZIP，解压后运行 `dist\WeChatLocalProfileEditor.exe`。
微信先保持登录，工具自动识别版本、数据目录、账号并读取联系人；可自选目录和账号、搜索昵称或原备注。

### 本机备注：手机 A、电脑 B

1. 选择已经有备注 A 的测试好友，在右侧输入电脑希望显示的 B，点击“本机备注覆盖试验”。
2. 阅读提示，保持工具打开，完全退出微信（含托盘），再确认。工具自动备份、检查副本、单次试写并开始只读采集。
3. 登录电脑微信，检查名称是否 B，并检查手机是否仍是 A。
4. 点击“结束备注诊断并复制报告”，直接粘贴反馈即可；报告不含实际昵称、备注或身份。

A/B 配置独立于头像持久保存，下次选中好友自动填入 B，无需重复输入。
“恢复电脑原备注缓存”只写回保存的 A；“清除本机备注配置”仅清除工具记录，不恢复微信。
“备注故障恢复”只处理能识别的未完成联系人库写入；禁止删除联系人记录。
此功能不保证客户端搜索、会话标题及资料页都采用本字段，也不保证保存的 A 仍是服务器当前值。
详见 [本机备注实现与边界](docs/LOCAL_REMARK.md)。

### 头像

选择 JPG/PNG/WEBP，工具自动裁切为兼容 PNG。可先保存头像配置，再按界面要求完成副本检查和试验写回。
新版普通“应用头像”默认禁止，需选择副本检查后的“仅本次试验应用”，或使用“开始一键诊断（保留字段）”。
后者自动复用保存的图片，明确确认后完成备份和试写；登录微信后点击结束即可复制脱敏报告。

每次打开检查保存配置；账号尚未解锁时显示“无法验证”。头像字节变化且有应用历史时提示本地替换失效，
可以复用已保存图片重新应用；字节相同也只标记数据库范围一致，不能凭此标为客户端“修改有效”。
“清除选中配置”仅删除工具头像配置；“恢复当前真实头像”清除该好友的头像缓存记录，让微信尝试重新获取当前头像，不写回旧头像。
恢复和失效重应用的完整真实客户端流程尚未验收。

## 写入和隐私边界

- 所有写入前要求微信完全退出，独占目标主库、现有 WAL/SHM，备份全部原始字节。
- 在私有加密副本中恢复已提交 WAL、验证逐页 HMAC、完整性、目标记录与其他数据不变，再写回改变的页。
- 失败时回滚整组三文件；无法识别的部分写入或外部变化会停止并保留备份，不盲目覆盖。
- 头像写入仅限 `head_image.db`；备注试验仅限 `contact.db`。不写聊天数据库、不创建同步提交操作，不自动结束微信。
- 备注试验只改 remark，保留原昵称、身份、同步标志及所有其他数据表；未知触发器或格式拒绝。
- **不要手动删除 WAL/SHM，也不要用解密 SQLite 覆盖微信加密数据库。**
- 仅支持通过校验的 SQLCipher4：32 字节 raw key、4096 页、80 字节保留区；未知格式拒绝。

配置和加密备份位于 `%LOCALAPPDATA%\WeChatLocalProfileEditor`；原头像、自定义图片、A/B 文字均保存副本。
备份包含私人联系人数据，不要上传。正常流程清理解密暂存目录，强制终止或断电可能遗留临时文件。
不上传微信资料，不在日志或诊断报告中记录密钥、消息、姓名或备注；Python 不能保证内存密钥完全擦除。
采样线程约三分钟自动停止，工具退出不保留采集进程。诊断报告只含版本、相对时间和变化状态，不能证明具体写入进程或同步机制。

## 构建与源码运行

Actions `Windows experimental avatar editor build` 自动运行 Windows 测试、PyInstaller 单文件打包，
并实际启动 EXE，用全新人工加密数据库测试头像、备注 A→B→A、字段保留、只读采样和 Qt 启停。
这些检查不能代替真实微信验收。完整源码在本仓库，许可证与上游复用见 [NOTICE](third_party/NOTICE.md)。

Windows x64、Python 3.12 源码运行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-research.txt
.\.venv\Scripts\python.exe tools\run_tests.py
if ($LASTEXITCODE -ne 0) { throw '测试失败，请停止' }
.\.venv\Scripts\python.exe main.py
```

普通 EXE 用户不需要上述命令。Linux 开发设置 `QT_QPA_PLATFORM=offscreen` 并运行相同测试入口。
