# 微信本地身份工具 1.0

Windows x64 单文件 `WeChatLocalProfileEditor.exe`。双击使用，无需安装 Python；无服务、驱动、计划任务、常驻 Hook 或托盘后台进程。

## 下载与使用

在本仓库 Actions 的 **Windows release build** 最新成功记录中，下载 `WeChatLocalProfileEditor-1.0-Windows-x64` 压缩包，解压运行 `dist\WeChatLocalProfileEditor.exe`。

1. 保持微信登录，打开工具读取联系人。支持自选数据目录、账号，以及昵称/备注/微信 ID 搜索。
2. 选择好友，选择新头像并点击“应用头像至微信”，或输入文字并点击“应用电脑备注”。两项独立操作。
3. 保持工具打开，正常退出微信（包括托盘），按提示确认。工具自动检查加密副本、备份、写入和校验。
4. 启动微信查看效果；完成后可退出工具，不需要常驻。

旧版配置自动沿用：配置目录仍为 `%LOCALAPPDATA%\WeChatLocalProfileEditor`，不需重新选择已保存的图片或输入备注。

每次读取账号后自动检查已保存配置；发现变化可“一键重新应用”，复用保存的头像和文字。
账号尚未读取时显示“无法验证”；检查范围是当前本机数据库，不能自动确认微信实际画面。
“保存头像配置”仅保存工具配置；“清除选中配置”仅删除头像配置，不恢复微信。
“恢复当前真实头像”清除指定好友的头像库缓存记录，让微信重新获取头像，不写回可能过时的旧图。
“恢复电脑原备注缓存”写回首次保存的备注，可能与服务器当前备注不同。
维护菜单提供备注配置清除、未完成写入恢复与验证范围说明。正常操作不采样、不要求复制调试报告。

## 支持与实测范围

- **微信 4.1.15.56**：用户已确认选定好友的头像、电脑自定义备注生效且重启后保留；手机备注没有变化。
- 头像仅修改 `image_buffer`，保留原 `md5`、时间等字段；电脑备注仅修改本机 `contact.remark`，保留昵称、身份、同步标志和其他数据表。
- 实测为用户选定好友及当前环境，不代表所有界面、好友、手机以外的设备或将来同步行为均已验收。工具不调用官方备注提交接口。
- 4.1.13.65 保留已有头像适配，未完成客户端验收；4.1.15.65 仅支持读取，正式界面禁止写入；未知版本禁止读取、写入。更新微信后需要重新适配。
- 失效检测/重新应用、清缓存恢复头像的完整真实客户端流程仍待验收。自动化测试不代替真实微信验证。

## 数据安全

所有修改必须先完全退出微信。自动独占目标主库及现有 WAL/SHM、建立一致性备份；在私有加密副本中检查 WAL、逐页 HMAC、完整性、目标记录和其他数据不变后，才写回改变的页。
失败自动回滚；遇到无法确认的中断状态停止并保留备份。不要手动删除 WAL/SHM，不要用解密 SQLite 覆盖原加密库。
仅写头像库或联系人库，不写聊天数据库，不上传微信资料，不记录密钥、消息、姓名或备注到错误报告。
备份包含私人联系人数据，请勿上传。异常退出可能遗留临时文件；Python 无法保证内存密钥完全擦除。

检测到微信主程序时要求正常退出。只有残留附属组件、身份与安装目录均可核实时，才提供用户明确选择的“结束残留组件并重试”，不会自动结束微信主程序。该选项可能丢失未保存的小程序/网页内容。
报错时可从弹窗复制脱敏报告；原始异常消息、姓名、备注、路径或密钥不出现在报告中。

## 源码与构建

Windows x64，Python 3.12：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-research.txt
.\.venv\Scripts\python.exe tools\run_tests.py
if ($LASTEXITCODE -ne 0) { throw '测试失败，请停止' }
.\.venv\Scripts\python.exe main.py
```

普通 EXE 用户不需要命令。Windows Actions 运行测试、PyInstaller 单文件打包，并实际启动打包 EXE，在人工加密数据上自检头像、备注 A→B→A、字段保留与 Qt 启停。Linux 开发使用 `QT_QPA_PLATFORM=offscreen`。
完整源代码在本仓库，使用的项目、许可证和复用说明见 [NOTICE](third_party/NOTICE.md)。
